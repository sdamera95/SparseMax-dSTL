# SparseMax-DiffSTL

Research implementation on SEIL-sandeep. The manuscript is maintained separately under SparseMax-DSTL on the Mac. Current scope: masked scalar operators, numerical audits, contact-free differentiable-MJX and cross-simulator checks, and a small double-integrator pilot. This is not yet a complete STL backend or robotics benchmark.

## Environment

Python 3.13.12 is pinned in .python-version. Dependencies are declared in pyproject.toml and resolved in uv.lock. The .venv was created using plain uv venv.
